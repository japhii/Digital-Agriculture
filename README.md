# MyAgrii - Agricultural Machine Learning Platform

This repository contains the deployment configuration for the MyAgrii application, a comprehensive machine learning platform for agriculture, including:
- Crop Recommendation
- Disease Prediction
- Drought Prediction
- Soil Suitability Analysis

The backend is built with Flask and the frontend with React.

## Running Locally
```bash
pip install -r requirements.txt
python app.py
```
